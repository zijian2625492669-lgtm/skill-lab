# skill-lab

Personal AI / automation / coding skill collection.

用于沉淀 AI skill、Prompt 工程、Agent 设计、自动化流程、数据分析脚本和小型实验项目的个人知识与实践仓库。

## 目录结构

| 目录 | 用途 |
| --- | --- |
| `prompts/` | Prompt 工程、System Prompt、提示词模板 |
| `dify/` | Dify 工作流、DSL、节点设计、Agent 配置 |
| `agents/` | Agent 设计、多 Agent 架构、任务拆分、工具调用 |
| `crawler/` | 爬虫相关，包含 Firecrawl、Playwright、数据抓取 |
| `automation/` | 自动化流程、批处理、工作流、自动运营 |
| `python/` | Python 工具脚本、数据处理、实验代码 |
| `analytics/` | 数据分析、A/B Test、统计分析、实验设计 |
| `ai-tools/` | AI 工具研究，包括 OpenAI、Claude、Cursor、OpenCode 等 |
| `docs/` | 学习文档、笔记、教程、经验总结 |
| `templates/` | 可复用模板、README 模板、项目模板、工作流模板 |
| `assets/` | 静态资源、图片、截图、素材、演示文件 |
| `projects/` | 小型练手项目、Demo、实验项目、测试工程 |
| `archive/` | 废弃内容、老版本、过期实验、历史文件 |

## 使用约定

- 所有文本文件默认使用 UTF-8 编码。
- 新内容优先放入对应主题目录，避免堆在仓库根目录。
- 过期但仍有参考价值的内容移动到 `archive/`。
